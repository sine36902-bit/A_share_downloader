# A_share_downloader
# A 股历史行情下载器

一个在自己电脑上运行的小工具，用来下载股票和指数的历史行情，并保存为 Excel 或 CSV 文件。

使用时需要联网，不需要搭建网站或服务器。

## 代码在哪里？

可以通过以下两种方式获取：

- **Code 页面**：在仓库文件列表中找到需要的 `.py` 文件，打开后下载；也可以点击绿色的 **Code → Download ZIP**，下载整个项目并解压。
- **Issues 页面**：在对应 Issue 中查看和复制代码。

## V1 和 V2 有什么区别？

| 功能 | V1 基础版 | V2 进阶版 |
| --- | --- | --- |
| 程序文件 | `a_share_downloader.py` | `a_share_downloader_V2.py` |
| 查询对象 | 每次一只 A 股股票 | 支持多只股票和指数混合查询 |
| 行情周期 | 日线 | 日线、周线、月线 |
| 导出字段 | 日期、收盘价 | 日期和收盘价必选，其他字段可选 |
| 数据预览 | 不提供 | 可切换查看各证券的前 10 行数据 |
| 导出格式 | Excel | Excel、CSV |
| 批量导出 | 不支持 | Excel 多工作表或 CSV 多文件 |
| 下载说明 | 简单状态提示 | 记录数据来源、日期范围、复权口径及成功或失败状态 |
| 失败处理 | 报错后可重新下载 | 可单独重新获取失败或无数据的项目 |

两个版本都支持股票的不复权、前复权和后复权。V2 中的指数使用独立的数据口径，不套用股票复权。

**只想下载一只股票的历史收盘价，可以选 V1；需要批量下载、指数数据或更多字段，可以选 V2。**

## 新手使用步骤

1. 下载需要的版本，将 `.py` 文件放进一个单独的文件夹。如果下载的是 ZIP，请先解压。
2. 安装上面任意一款 AI 编程工具。
3. 用该工具打开存放程序的文件夹。
4. 在工具里的 AI 对话框中发送下面这段话：

> 我完全不会编程，想在自己的电脑上运行这个股票行情下载器。请查看当前文件夹里的 Python 程序，检查并配置 Python 环境、安装需要的依赖，然后启动程序。如果文件夹里同时有 V1 和 V2，请先帮我运行 V2。遇到报错请帮我排查。需要我手动操作的地方，请一步一步说明，不要一次给太多步骤。只需要在本地运行，不需要部署网站或云服务。

如果是从 Issue 中复制代码，也可以把完整代码发给 AI，让它帮你保存成对应的 `.py` 文件。

过程中可能需要你确认安装或执行命令。如果不理解某一步，可以继续让 AI 解释。

## 程序启动后怎么用？

**V1 基础版：**

1. 输入一只股票的六位代码，例如 `600519`。
2. 填写开始日期和结束日期，选择复权方式。
3. 选择保存目录，点击“下载并导出”。

**V2 进阶版：**

1. 输入股票或指数代码，例如：`600519, 股票:000001, 指数:000300`。
2. 选择日期范围、行情周期、复权方式和数据字段。
3. 点击“获取并预览”，检查下载结果。
4. 选择保存目录和 Excel / CSV 格式。
5. 点击“导出数据”。

V2 中，普通六位代码默认为股票，查询指数时需要加上 `指数:` 前缀。例如，`000001` 表示平安银行，`指数:000001` 表示上证指数。

## 想修改功能？

可以直接用中文告诉 AI 编程工具，例如：

> 请把默认开始日期改为 2020 年 1 月 1 日，其他功能保持不变。

修改前建议备份原文件，方便出现问题时恢复。

## 注意事项

- 行情通过 AKShare 获取，来自公开行情数据源，可能受网络、接口变更或数据源限制影响。
- 部分证券或日期范围可能没有数据，程序不会编造、插值或补齐缺失价格。
- 指数接口可能只返回部分历史数据，实际获取范围以程序显示和导出的记录为准。
- AI 编程工具可以协助排查问题，但不能保证解决所有网络或数据源故障。
