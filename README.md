# A_share_downloader
# A 股历史行情下载器

一个在自己电脑上运行的小工具，用来下载股票和指数的历史行情，并保存成 Excel 或 CSV 文件。

支持多只证券批量查询、自选日期范围、日线/周线/月线、数据预览和导出。使用时需要联网，不需要搭建网站或服务器。

## 代码在哪里？

**完整代码放在本项目的 Issues 中。** 打开对应 Issue，即可查看和复制代码。

## 不会编程，怎么运行？

中国内地的同学可以优先考虑 **CodeBuddy 中国版或 TRAE 中国版**。下面的工具任选一个即可，不用全部安装。

| 工具 | 简单介绍 | 官方入口 |
| --- | --- | --- |
| CodeBuddy 中国版 | 腾讯的 AI 编程工具，支持 Windows 和 Mac。新手选择 CodeBuddy IDE 桌面版即可。 | [官方下载](https://www.codebuddy.cn/downloads/) |
| TRAE 中国版 | 提供中文使用支持，可以通过对话协助修改代码、运行项目和排查问题。 | [中国版官网](https://www.trae.com.cn/) |

## 新手使用步骤

1. 安装上面任意一款 AI 编程工具。
2. 在电脑上新建一个文件夹，用该工具打开。
3. 从本项目的 Issue 中复制完整代码。
4. 把代码发给工具里的 AI 助手，再发送下面这段话：

> 我完全不会编程，想在自己的电脑上运行这个股票行情下载器。请帮我把代码保存为 a_share_downloader_V2.py，检查并配置 Python 环境、安装需要的依赖，然后启动程序。如果报错，请帮我排查。需要我手动操作的地方，请一步一步说明，不要一次给太多步骤。只需要在本地运行，不需要部署网站或云服务。

过程中可能需要你确认安装或执行命令。如果不理解某一步，可以继续让 AI 解释。

## 程序启动后怎么用？

1. 输入股票或指数代码，例如：`600519, 股票:000001, 指数:000300`。
2. 选择开始日期、结束日期、行情周期和需要的数据字段。
3. 点击“获取并预览”，检查下载结果。
4. 选择保存目录和 Excel / CSV 格式。
5. 点击“导出数据”。

普通六位代码默认为股票，查询指数时需要加上 `指数:` 前缀，避免同名代码混淆。

## 想修改功能？

可以直接用中文告诉 AI 编程工具，例如：

> 请把默认开始日期改为 2020 年 1 月 1 日，其他功能保持不变。

修改前建议备份原文件，方便出现问题时恢复。

## 注意事项

- 行情来自公开数据接口，可能受网络、接口变更或数据源限制影响。
- 部分证券或日期范围可能没有数据，程序不会编造或补齐缺失价格。
- AI 编程工具可以协助排查问题，但不能保证解决所有网络或数据源故障。
